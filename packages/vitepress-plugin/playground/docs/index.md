# lhx-spec-hub playground

This is a live rendering of `@luhanxin/spec-hub-vitepress-plugin` against `yjs-docs`'s real
`openspec/` content. Regenerated by `pnpm playground:sync` (also runs automatically before
`playground:dev`/`playground:build`).

- Browse a capability contract: [`error-monitor`](/lhx-space/yjs-docs/specs/error-monitor)
- Browse why a past decision was made: [`error-monitor-network-support`](/lhx-space/yjs-docs/changes/error-monitor-network-support)

The sidebar (left) is generated too — try switching between the two namespaces above.
